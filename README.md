A modern, fast, and feature-rich **Holy Quran Application** built using **Flutter**. The app fetches precise Quranic data, translations, and audio recitations via asynchronous REST API integrations, delivering a clean and seamless reading experience across mobile platforms.

---

## ✨ Features & Highlights

* 📖 **Complete Quranic Text:** Read the Holy Quran organized both Surah-wise and Ayah-wise.
* 🎧 **Audio Recitations:** High-quality verse-by-verse and full Surah audio streaming support.
* 🌍 **Multi-Language Translations:** Access Quranic interpretations and translations in various international languages.
* 🔎 **Search & Filter:** Quick Surah search with revelation type (Meccan/Medinan), total verses, and translation details.
* ⚡ **High-Performance API Sync:** Asynchronous HTTP/Dio architecture for rapid caching and offline readiness.
* 📱 **Responsive Material UI:** Elegant, distraction-free reading interface with full light and dark theme compatibility.
